# Review usage

The Usage page combines Codex, Claude Code, and OpenRouter activity from your connected
environments. It reads the providers' local session history and shows an estimated AUD token cost,
processed tokens, cache savings, provider shares, and model breakdowns.

OpenRouter turns are priced from OpenRouter's published catalogue rates. Claude and Codex turns
use the LiteLLM rate table, or an explicit cost written into the transcript when one exists. USD
figures are converted to AUD with a mid-market Frankfurter rate for the whole window. This is not
your OpenRouter invoice, your card's FX, or subscription billing.

Use **Past 24h** for an hourly chart covering the exact rolling 24-hour period. The **7 days**,
**30 days**, and **90 days** ranges use daily resolution. Cost and token toggles update both the
headline and chart, and refreshing rescans every connected environment.
